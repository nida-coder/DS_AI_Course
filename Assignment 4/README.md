# 📊 Week 4: Statistics & Probability – Correlation Analysis

## 📁 Project Title
**Customer Churn Prediction – Correlation Analysis**

---

## 🎯 Objective
The goal of this week’s task is to explore the dataset statistically and identify the key factors that influence customer churn.  
We calculate descriptive statistics and perform correlation analysis to find which features are most related to the target variable **(Churn)**.

---

## 🧮 Key Tasks
### 1. Descriptive Statistics
- Calculated **mean**, **median**, **mode**, and **variance** for all numeric columns.  
- Summarized dataset to understand the distribution and central tendency.

### 2. Correlation Analysis
- Computed **correlation matrix** to measure the strength of relationships between features.  
- Visualized correlations using a **heatmap** for better interpretation.

### 3. Key Insights
- Identified **top 3 features** most related to the target variable (`Churn`).
- These features are likely to be **key predictors** for modeling in later weeks.

---

## 🧠 Tools & Libraries Used
- **Python 3**
- **Pandas** – Data manipulation
- **NumPy** – Numerical operations
- **Matplotlib** & **Seaborn** – Data visualization

---

## 📈 Results
- Produced a **Correlation Heatmap** showing relationships between all numeric variables.
- Highlighted **top 3 correlated features** with `Churn`.
- Insights will guide **feature selection** for predictive modeling in Week 5.
